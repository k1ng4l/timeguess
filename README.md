# TIMEGUESS

**Многопользовательская игра на чувство времени.**

TIMEGUESS — онлайн-игра, в которой игроки проверяют своё чувство времени и соревнуются друг с другом.

🌐 **Играть:** https://timeguess.onrender.com

## Возможности

- Игровые комнаты для нескольких игроков.
- До 7 игроков в одной комнате.
- Настройка профиля пользователя.
- Загрузка аватара.
- История матчей и статистика.
- Настройки приватности.
- Защита и проверка имён пользователей.

## Технологии

Проект разработан с использованием:

- **Python** и **FastAPI** — серверная часть.
- **PostgreSQL** — хранение данных.
- **JavaScript** — логика игры.
- **HTML и CSS** — интерфейс.
- **Render** — размещение проекта.

## Текущая версия
